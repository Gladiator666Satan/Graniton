## 📌 Про проєкт

**Graniton** — це високопродуктивний кастомний клієнт на базі офіційного вихідного коду Telegram Android v13.1.1, скомпільований виключно під 64-бітну архітектуру `arm64-v8a` та повністю оптимізований для флагмана **Samsung Galaxy S26 Ultra**.

Застосунок має власний ідентифікатор пакету (`org.graniton.messenger`), що дозволяє встановлювати його паралельно з оригінальним клієнтом Telegram, не конфліктуючи з ним.

## ⚡ Ексклюзивний пакет Power-Pack (Гілка feature/power-pack)

* 🎥 **HD 60fps кружечки (Video Notes)**: Запис нативних круглих повідомлень у 384×384 при 60 кадрах/с із підвищеним студійним бітрейтом (2.5 Мбіт/с) замість стандартних 30fps / 1.0 Мбіт/с зі 100% збереженням круглого формату MTProto.
* 💣 **Збереження та скриншоти зникаючих медіа («бомбочок»)**: Повне розблокування перегляду, збереження та зйомки екрана для зникаючих фото та відео (View-Once / TTL). У переглядачі SecretMediaViewer додано фірмову кнопку збереження в галерею, вимкнено примусове автовидалення медіа після закінчення таймера, дозволено створення скриншотів та збереження через контекстне меню чату.
* 🙈 **Виправлення медіа-спойлерів**: Коректна передача атрибута прихованого контенту (`hasMediaSpoilers`) на сервери MTProto для фото та відео (отримувач тепер бачить спойлер розмитим).
* 🔒 **Повне брендування коду доступу та біометрії**: Динамічний перехоплювач мовного рушія (`LocaleController`) замінює всі форми згадок Telegram на Graniton у системних діалогах автентифікації, коду доступу та відбитка пальця.
* 🤖 **Брендування системних чатів**: Сповіщення безпеки та авторизації відображаються як «Graniton Notifications» та «Graniton Support» замість Telegram.
* 🕵️ **True Ghost Mode (Режим «Привид»)**: Повне приховування активності введення (`sendTyping`) — співрозмовники ніколи не бачать статусів *«друкує...»*, *«записує голосове...»* чи *«надсилає файл...»*.
* 🛡️ **Anti-Delete Protection**: Ігнорування віддалених команд видалення (`TL_updateDeleteMessages`). Якщо співрозмовник або адмін видаляє повідомлення «для всіх», воно назавжди залишається у вашій локальній історії чату.
* 🔓 **Bypass Restricted Content (`noforwards`)**: Знято блокування на збереження фото/відео в галерею та пересилання повідомлень із захищених каналів і чатів.
* 👑 **Client-Side Premium Features**: Розблоковано кнопку нативного розпізнавання голосових у текст (Voice-to-Text), миттєвий переклад усього чату та повне блокування рекламних спонсорських повідомлень (Ad-Free).
* ⚡ **Force 120Hz Fluidity**: Примусове апаратне блокування максимальної частоти оновлення дисплея (120Hz) для динамічних AMOLED-екранів флагманів Galaxy S26 Ultra.

## ✨ Ключові можливості та модифікації

### 🔮 1. Фірмовий дизайн та брендинг
* **Преміальний логотип у шапці (GRANITON Wordmark)**: Замінено старий курсивний напис «Telegram» на сучасний векторний логотип **GRANITON** у шапці головного екрана та в блоці Stories (`telegram_logo_2.xml`). Логотип має бездоганну геометрію з рівною висотою літер та елегантним трекінгом, позбавлений будь-яких нерівностей.
* **Dark Violet / Purple Energy Theme**: Глибока нічна палітра інтерфейсу (`#0d0214`, `#08000c`, `#160926`) із насиченими неоново-фіолетовими акцентами (`#8b2be2` / `#9333ea`) замість стандартного синього кольору Telegram.
* **Повна кастомізація системних сповіщень (Notification Branding)**: Замінено всі ідентифікатори сповіщень у системній шторці Android та на екрані блокування Samsung One UI (`Notification.EXTRA_SUBSTITUTE_APP_NAME`, `NotificationHiddenName`, `NotificationHiddenChatName`, `SecretChatName`) на **Graniton**. Тепер сповіщення як під час надходження (heads-up банер), так і в розгорнутому стані підписані виключно як «Graniton».
* **One UI Adaptive Icon**: Спеціальна адаптивна іконка для Android 14/15/16 та оболонок Samsung One UI. Логотип центровано з безпечними відступами (safe margins ~72%) на фірмовому темно-фіолетовому фоні, повністю замінено застарілий паперовий літачок.
* **Унікальний Package ID**: `org.graniton.messenger`.

### 🛡️ 2. Конфіденційність та свобода медіа
* **Збереження зникаючих фото та відео**: Знято блокування на збереження медіафайлів із таймером самознищення («бомбочкою») — їх можна вільно зберігати напряму в галерею смартфона.
* **Повне вимкнення FLAG_SECURE**: Дозволено створення скриншотів та запис відео з екрана у таємних чатах (Secret Chats), захищених каналах із забороною копіювання (`noforwards`) та в меню перегляду профілів.
* **Режим «Привид» для сповіщень**: Вимкнено примусове надсилання звітів про прочитання при переході за згадками (`markMentionsAsRead`), що дозволяє переглядати контекст без викриття своєї присутності.

### ⚡ 3. Апаратний буст для Samsung Galaxy S26 Ultra
* **Незжата якість камери та фото**: Знижено агресивне стиснення медіа при зйомці на потужний сенсор камери Galaxy S26 Ultra.
* **Тільки ARM64-v8a**: Повністю вирізано застарілі 32-бітні бібліотеки (`armeabi-v7a`, `x86`, `x86_64`), що суттєво зменшило розмір APK, оптимізувало час компіляції та пришвидшило роботу застосунку на сучасних 64-бітних процесорах Snapdragon 8 Elite.

## 🛠️ Збірка та CI/CD

Проєкт повністю автоматизований через **GitHub Actions**:
1. При кожному пуші у гілки `master` та `feature/power-pack` автоматично запускається воркфлоу `.github/workflows/build.yml`.
2. Всі модифікації застосовуються атомарно через безпечні Python-скрипти.
3. Готовий підписаний APK автоматично публікується як GitHub Release із відповідним тегом версії та білда.
